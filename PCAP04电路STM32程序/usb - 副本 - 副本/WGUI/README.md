# USB 2.0 数据接收 - 16x16矩阵显示程序 (WPF版本)

这是一个C# WPF应用程序，用于通过USB CDC（虚拟串口）接收数据，并在16x16矩阵中实时显示。采用Mac风格设计。

## 功能特性

- ✅ USB CDC串口通信（自动识别虚拟串口）
- ✅ 16x16矩阵实时数据显示（十六进制和浮点数格式）
- ✅ 原始数据十六进制/字符串显示
- ✅ 接收字节数统计
- ✅ 数据值颜色可视化（值越大颜色越深）
- ✅ Mac风格现代化UI设计
- ✅ 可拖拽分隔条调整布局
- ✅ 自动重连功能

## 系统要求

- Windows 10/11
- .NET 8.0 或更高版本
- USB CDC设备（STM32虚拟串口）

## 编译和运行

### 方法1：使用Visual Studio
1. 打开 `USBMatrixDisplay.csproj`
2. 按 F5 运行

### 方法2：使用命令行
```bash
cd WGUI
dotnet build
dotnet run
```

### 方法3：使用批处理脚本
```bash
cd WGUI
build.bat    # 编译
run.bat      # 运行
publish.bat  # 发布可执行文件
```

### 方法4：发布可执行文件
```bash
cd WGUI
dotnet publish -c Release -r win-x64 --self-contained
```

## 使用方法

1. **连接设备**：将STM32设备通过USB连接到电脑
2. **选择串口**：在程序中选择对应的COM端口（通常是COM3, COM4等）
3. **点击连接**：建立与设备的通信
4. **查看数据**：
   - 左侧16x16矩阵显示接收到的数据（十六进制或浮点数）
   - 右侧文本框显示原始接收数据
   - 状态栏显示连接状态和接收字节数
5. **调整布局**：可以拖拽中间的分隔条来调整左右面板的大小

## 显示模式

- **十六进制模式**：每个字节显示为十六进制值（00-FF）
- **字符串模式**：解析文本中的浮点数值并填充到矩阵中

## 数据格式说明

- 矩阵按行优先顺序填充数据
- 每个单元格显示一个字节的十六进制值或浮点数值
- 数据值越大，单元格背景颜色越深（蓝色调）
- 如果一次接收超过256字节，只显示前256字节

## 串口配置

默认配置：
- 波特率：115200
- 数据位：8
- 校验位：无
- 停止位：1

如需修改，请在 `MainWindow.xaml.cs` 的 `ConnectToPort` 方法中调整。

## 自动重连

启用"自动连接"复选框后，程序会自动检测并连接STMicroelectronics Virtual COM Port设备。

## 注意事项

- 确保STM32设备已正确配置为USB CDC模式
- 如果找不到串口，点击"刷新"按钮
- 断开连接前请先点击"断开"按钮
- 程序会自动限制显示缓冲区大小，避免内存溢出
